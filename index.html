The Conductor

json-api-builder (Orchestrator)

Instead of manually calling 7 separate libraries, the orchestrator ties every link in the chain with single-call simplicity.

build.js 
import { build } from "json-api-builder";

// One call conducts all 7 stages seamlessly:
const result = build({
  clientRoot: process.cwd(),
  outputRoot: "./dist/api"
});

console.log(`Server ready at: ${result.appPath}`);
console.log(`Integrity check: ${result.validation.valid}`);

The 8 Sibling Repositories

Independent npm modules built for resilience and clear separation of concerns

json-api-builder-validation

Repo Story →

Guards inputs and proves output validity. Pre-flight schema checks prevent incomplete builds; post-flight inspections verify generated routes & syntax.

Exports: validateConfiguration, verifyGeneratedApp

json-api-builder-create-folders

Repo Story →

Scaffolds directory hierarchies from tree definitions using deterministic traversal. Creates zero phantom paths.

Exports: createFolders

json-api-builder-create-files

Repo Story →

Provisions the skeleton files within established folders so subsequent AST parsers have valid targets.

Exports: createFiles

json-api-builder-insert-content

Repo Story →

Converts abstract syntax trees (ESTree) and JSON data schemas into code modules using astring compiler.

Exports: insertContent

json-api-builder-alter-content

Repo Story →

Modifies existing files to wire sub-router chains into their parents, producing clean modular routing without regex hacks.

Exports: hookRoutes

json-api-builder-create-app

Repo Story →

Emits app entrypoint (`app.js`), loads configured strategies, and sets up `@hono/node-server` listeners.

Exports: createApp, hookAppStrategies, startServer

json-api-builder-create-endpoints

Repo Story →

Constructs standard HTTP route handlers (GET, POST, PUT, DELETE) and file sync endpoints for disk collections.

Exports: createEndpoints, createFileSyncEndpoint

json-api-builder-orchestrator

Repo Story →

The single public facade uniting the entire suite into a one-function `build()` invocation with automatic clientRoot resolution.

Exports: build
