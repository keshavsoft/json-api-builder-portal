Dynamic AST Router Wiring

json-api-builder-alter-content

Connects sub-routers into their parent routers across the tree by injecting AST import and mount statements without string search-and-replace or regex tampering.

The Hooking Challenge

How do deeply nested endpoints like `/api/v1/clinics` hook into `/api/v1`, and then into `/api`? Trying to regex parse code to find where to put `import` and `app.route(...)` is notoriously fragile.

The hookRoutes Solution

Injects AST import nodes (`import clinicsRoutes from "./clinics/routes.js"`) and AST route call expressions (`routes.route("/clinics", clinicsRoutes)`) into the parent file cleanly.

Usage in Pipeline 

import { hookRoutes } from "json-api-builder-alter-content";

hookRoutes({
  clientRoot: process.cwd(),
  outputRoot: "./output"
});
