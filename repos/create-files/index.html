Target File Provisioning

json-api-builder-create-files

Plants the physical file nodes across the scaffolded directory structure so downstream AST code injectors and templates have guaranteed target handles.

The Problem

Code generators attempting to write code directly to non-existent files trigger I/O descriptor errors or race conditions if file creation isn't isolated as an atomic prerequisite stage.

The Solution

Traverses the tree to create clean placeholder files (`api/routes.js`, `api/v1/routes.js`, `api/v1/clinics/routes.js`) and copies initial dataset files into the output directory.

API Usage 

import { createFiles } from "json-api-builder-create-files";

createFiles({
  clientRoot: process.cwd(),
  outputRoot: "./output"
});
