Hono Server Bootstrap

json-api-builder-create-app

Creates the master application entrypoint (`app.js`), loads configured strategies, and sets up `@hono/node-server` listeners for instant local preview or cloud deployment.

The Problem

Individual route files cannot run by themselves. They need a top-level application instance that binds middleware, handles error boundaries, and provides an HTTP listener.

The Hono Runner

Generates `app.js` using ultrafast modern Hono syntax, exposes `startServer()`, and attaches operational strategies (such as file-sync or CORS middleware).

Usage in Pipeline 

import { createApp, hookAppStrategies } from "json-api-builder-create-app";

createApp({ clientRoot: process.cwd(), outputRoot: "./output" });
hookAppStrategies({ clientRoot: process.cwd(), outputRoot: "./output" });

// Output: output/app.js ready to start on port 3000
