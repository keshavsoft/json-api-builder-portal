Pre-flight Contract & Post-flight Verification

json-api-builder-validation

The guardian that bookends the entire generation process. It prevents bad builds before anything touches disk and certifies that the generated backend is syntactically sound and complete.

The Problem It Solves

Code generators that fail midway leave corrupt directory trees and broken JS files. Without strict pre-flight checks, a missing `tree.json` or invalid JSON syntax triggers runtime crashes deep inside the pipeline.

The Dual-Phase Guarantee

validateConfiguration() validates that input configurations, schema types, and data paths exist. verifyGeneratedApp() ensures all expected routes and `app.js` are generated and syntax-valid.

API & File Structure 

// src/index.js exports:
export { validateConfiguration } from "./v1/validate-configuration.js";
export { verifyGeneratedApp } from "./v1/verify-generated-app.js";

// 1. Before Build Starts:
validateConfiguration({ clientRoot }); // Throws descriptive error if invalid

// 2. After Build Finishes:
const status = verifyGeneratedApp({ clientRoot, outputRoot });
// Returns: { valid: true, errors: [], warnings: [] }
