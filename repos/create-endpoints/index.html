CRUD & File Sync Handler Generator

json-api-builder-create-endpoints

Generates full CRUD endpoints (GET list, POST create, GET read, PUT update, DELETE delete) backed by JSON data files, plus file-sync endpoints for continuous data synchronization.

The Problem

Writing boilerplate CRUD logic for every collection and managing disk file synchronization is repetitive and leads to bugs and data serialization mismatch.

The Automation

Generates complete handlers connected to `data/clinics.json` and creates `/endpoints/fs/routes.js` to synchronize mock collections over simple HTTP calls.

Usage in Pipeline 

import { createEndpoints, createFileSyncEndpoint } from "json-api-builder-create-endpoints";

createFileSyncEndpoint({ clientRoot: process.cwd(), outputRoot: "./output" });
createEndpoints({ clientRoot: process.cwd(), outputRoot: "./output" });
