Authentic ESTree AST Compilation with Astring

Why AST & Why We Replaced Babel with Astring

Stage 3 proves that code generation shouldn't rely on string templating or bloated 50MB compiler toolchains. Here is the deep technical story behind how raw AST JSON turns into rock-solid Hono router code.

The Architectural Evolution

Comparing the three methods of code generation in JavaScript

1. Raw String Concatenation

Template literals (`\`import ...\``) or string replacement. Extremely fragile: quotes break, indentation fails, trailing commas cause silent parse errors, and escaping dynamic strings is a maintenance nightmare.

Verdict: Brittle & prone to runtime syntax failures.
2. Heavy Babel Toolchain

Babel (`@babel/core`, `@babel/generator`) provides genuine AST generation. But it pulls in 50+ MB of dependencies, uses a non-standard AST dialect, and carries immense performance overhead.

Verdict: Overkill, slow, and massive dependency bloat.
3. The Astring Engine

We adopted astring: weighing just ~10 KB with zero external dependencies. Follows authentic ESTree specification and generates clean JavaScript up to 50x faster than Babel.

Verdict: Zero bloat, instant execution, 100% valid code.

The Transformation in Action

From raw ESTree JSON AST into clean Hono boilerplate

Input: source-of-truth/routes.estree.json ESTree AST 
{
  "type": "Program",
  "sourceType": "module",
  "body": [
    {
      "type": "ImportDeclaration",
      "specifiers": [{
        "type": "ImportSpecifier",
        "imported": { "name": "Hono" },
        "local": { "name": "Hono" }
      }],
      "source": { "type": "Literal", "value": "hono" }
    },
    {
      "type": "VariableDeclaration",
      "kind": "const",
      "declarations": [{
        "id": { "name": "app" },
        "init": {
          "type": "NewExpression",
          "callee": { "name": "Hono" }
        }
      }]
    },
    {
      "type": "ExportDefaultDeclaration",
      "declaration": { "name": "app" }
    }
  ]
}
Output: generated routes.js astring.generate() 
import { Hono } from "hono";

const app = new Hono();

export default app;
How Stage 3 Executes This:

Stage 3 traverses `source-of-truth/tree.json`. For every file matching `routes.js`, it loads `routes.estree.json`, calls `astring.generate(ast)`, and writes the output directly to disk.
