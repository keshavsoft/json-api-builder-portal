json-api-builder-create-folders

Translates structural JSON specifications (`source-of-truth/tree.json`) into physical nested folder hierarchies using recursive depth-first traversal with zero phantom directories.

The Problem

Modern REST API frameworks like Hono rely on modular routing folders (`/api/v1/clinics`, `/endpoints/fs`). Hardcoding folder creation in build scripts creates brittle pipelines that break across operating systems.

The Engine

Powered by json-traversal-core, this stage parses any valid JSON hierarchy and creates every parent-child directory cleanly using atomic `fs.mkdirSync(..., { recursive: true })`.

How It Works in Code 

import { createFolders } from "json-api-builder-create-folders";

// Reads source-of-truth/tree.json:
createFolders({
  clientRoot: process.cwd(),
  outputRoot: "./output"
});

// Automatically builds:
// output/api/
// output/api/v1/
// output/api/v1/clinics/
