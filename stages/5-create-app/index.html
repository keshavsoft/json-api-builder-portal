Hono Server & Bootstrap Orchestrator

Stage 5: json-api-builder-create-app

Creates the master application entrypoint (app.js), wires CORS/logger/security strategies, and supplies an executable HTTP server runner using @hono/node-server.

The Problem

Routes are useless without a top-level application instance that binds middleware, handles 404/500 errors, and provides a runtime HTTP listener.

The Hono Engine

Generates an ultrafast Hono server, hooks configured app strategies, and exposes startServer() for immediate local preview or cloud container deployment.

API Usage 

import { createApp, hookAppStrategies, startServer } from "json-api-builder-create-app";

createApp({ clientRoot: "./my-project", outputRoot: "./dist" });
hookAppStrategies({ clientRoot: "./my-project", outputRoot: "./dist" });

// Optional: boot the server directly:
// startServer({ appPath: "./dist/app.js", port: 3000 });
