Stage 0 & 7: json-api-builder-validation

Before generating a single folder or file, we guarantee input contracts. And once generation is finished, we rigorously inspect all emitted code and artifacts to verify zero syntax errors and complete schema compliance.

The Problem Without This Stage

Silent build failures occur mid-pipeline when paths, input trees, or route configurations are malformed. Partial folders and broken files get dumped on disk, requiring messy cleanup and frustrating debugging.

The Solution & Guarantee

Dual-phase validation: validateConfiguration() validates inputs before a single byte touches the disk. verifyGeneratedApp() ensures the final app file, endpoints, and route maps exist and pass JS syntax validation.

Input & Output Contract

Inputs Required
{
  clientRoot: string,
  outputRoot?: string
}
Output Guaranteed
{
  valid: true,
  errors: [],
  warnings: []
}

API Usage Example 

import { validateConfiguration, verifyGeneratedApp } from "json-api-builder-validation";

// 1. Pre-flight check
validateConfiguration({ clientRoot: "./my-project" });

// 2. Post-build verification check
const status = verifyGeneratedApp({ clientRoot: "./my-project", outputRoot: "./dist" });
console.log(`Build status valid: ${status.valid}`);
