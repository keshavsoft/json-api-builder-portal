Stage 6: json-api-builder-create-endpoints

Generates full CRUD endpoints (GET, POST, PUT, DELETE) and file sync infrastructure (such as /endpoints/fs/routes.js) allowing clients to synchronize local JSON files directly over HTTP.

The Problem

Manually writing boilerplate file-sync endpoints or CRUD logic for every collection is tedious and prone to serialization discrepancies.

The Automation

Provides automated file-sync and collection-backed endpoints directly connected to mock datasets (`data/*.json`), delivering immediate working APIs.

API Usage 

import { createEndpoints, createFileSyncEndpoint } from "json-api-builder-create-endpoints";

createFileSyncEndpoint({ clientRoot: "./my-project", outputRoot: "./dist" });
createEndpoints({ clientRoot: "./my-project", outputRoot: "./dist" });
