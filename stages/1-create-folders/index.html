Directory Tree Scaffolder

Stage 1: json-api-builder-create-folders

Traverses JSON tree specifications using deterministic hierarchical depth-first search, producing the physical directory layout without placing a single phantom folder.

The Problem It Solves

Nested REST API routing requires strict folder hierarchies (`api/v1/users`, `endpoints/fs`, etc.). Hardcoded shell scripts or ad-hoc `mkdir` statements drift over time and break across Windows and POSIX systems.

The Solution & Guarantee

Powered by json-traversal-core, this stage guarantees recursive folder creation adhering strictly to the schema specification with full cross-platform path resolution.

Scaffolded Folder Hierarchy 

output/
├── api/
│   └── v1/
│       └── clinics/
├── endpoints/
│   └── fs/
└── data/

API Usage 

import { createFolders } from "json-api-builder-create-folders";

createFolders({
  clientRoot: "./my-project",
  outputRoot: "./dist"
});
