AST-Driven Code & Data Generator

Stage 3: json-api-builder-insert-content

Transforms Abstract Syntax Tree (ESTree) templates and JSON data specifications into syntactically valid JavaScript modules using astring.

The Problem with String Concatenation

Generating code using template strings or string concatenation leads to quote-escaping bugs, missing commas, invalid indentation, and difficult-to-maintain code generators.

The AST Solution

By modeling routes as pure ESTree JSON AST and emitting them with astring, the output code is 100% syntactically correct, beautiful, and completely deterministic every single time.

API Usage 

import { insertContent } from "json-api-builder-insert-content";

insertContent({
  clientRoot: "./my-project",
  outputRoot: "./dist"
});
