File Skeleton Provisioner

Stage 2: json-api-builder-create-files

Provisions placeholder file handles across the scaffolded directory structure so AST generators and template compilers have concrete targets.

The Problem

Downstream AST code generators need to operate safely on physical files without race conditions or missing file descriptor errors.

The Guarantee

Atomic file creation ensuring all required route files (`routes.js`), mock databases (`clinics.json`), and file-sync routes exist and are initialized cleanly.

API Usage 

import { createFiles } from "json-api-builder-create-files";

createFiles({
  clientRoot: "./my-project",
  outputRoot: "./dist"
});
