Hierarchical Route Linker

Stage 4: json-api-builder-alter-content

Binds child sub-routers to parent routers across the tree by injecting AST route import and mount statements without string manipulation or regex tampering.

The Hooking Problem

How do deeply nested routes like /api/v1/clinics get registered with /api/v1, and in turn with /api? Regex find-and-replace is brittle and easily breaks existing code.

The hookRoutes Solution

Parses parent route modules, injects child route import declarations and router.route() bindings via AST transforms, then cleanly serializes the modified module.

API Usage 

import { hookRoutes } from "json-api-builder-alter-content";

hookRoutes({
  clientRoot: "./my-project",
  outputRoot: "./dist"
});
