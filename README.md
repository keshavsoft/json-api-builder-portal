# JSON API Builder Portal

A pure UI documentation and showcase portal for the **JSON API Builder** ecosystem.

## Overview

This repository contains zero backend build scripts or complex compilers—it is a clean, single-page presentation explaining the modular stages and architectural story of the `json-api-builder` suite.

- **index.html**: Live responsive presentation portal powered by Tailwind CSS & Bootstrap Icons.
- **Story Arc**: Demonstrates how Stages 0 through 7 link together through `json-api-builder-orchestrator`.

## Hosting

Hostable directly via GitHub Pages or any static file server:
```bash
npx serve .
```
